# Nectra Honey Garden — isolated local concept

Run from the repository root: `node experiments/botanical-garden/serve.mjs`.
Open http://localhost:3012. Nothing in the existing storefront is replaced or imported.
No deployment, commits or backend changes. This directory is outside public and the live build.

Eight products, desktop hover/focus, touch selection, two-second sequential touch animation, pause control, reduced-motion support, local product dialogs, catalogue selector. Product dialogs intentionally do not invent new prices, ingredient declarations or provenance. Ginger uses Energy packaging; Tulasi uses Immunity packaging. The six studio jar photos are clipped at display time to retain original labels. They are not new alpha-channel exports.

Illustration: generated with built-in image generation. Brief: one continuous Indian botanical landscape, eight connected zones (hills, Coorg greenery, hanging kombu comb, roses, wildflowers, jamun, ginger, tulasi, neem), fine gouache, warm morning colours, no text or jars. Saved in assets/garden.png. This is conceptual scenery, not sourcing evidence.
